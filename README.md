# 🌾 Agrilite Market

Agrilite Market is a modern digital marketplace designed to connect farmers and buyers through a simple, accessible, and user-friendly platform.

## 🚀 Features

- 👨‍🌾 Farmer-focused marketplace
- 🛒 Buyer marketplace interface
- 📊 Market information and analytics
- 🌐 Multilingual-ready interface
- 📱 Responsive design
- ⚡ Built with React and Vite

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/Archiit-jain/Agrilite-Market.git
cd Agrilite-Market
```
## Install dependencies:
```bash
npm install
```
Start development server:
```bash
npm run dev
```
The application will then be available at the local URL shown in your terminal.
