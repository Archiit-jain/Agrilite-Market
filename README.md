# 🌾 Agrilite Market

Agrilite Market is a modern digital marketplace designed to connect farmers and buyers through a simple, accessible, and user-friendly platform.

## 🚀 Features

- 👨‍🌾 Farmer-focused marketplace
- 🛒 Buyer marketplace interface
- 📊 Market information and analytics
- 🌐 Multilingual-ready interface
- 📱 Responsive design
- ⚡ Built with React and Vite

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
